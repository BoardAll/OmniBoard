# 互动白板预留接口设计

- 文档版本：v1.0
- 状态：预留设计稿
- 所属文档：《白板软件设计文档 v0.5》《C++ 核心引擎接口设计 v1.0》《MCP Server 详细设计 v1.0》
- 适用范围：Flutter UI + C++ 核心 + mediasoup + 现有 C++ / TCP / Socket.IO 库
- 定位：本阶段不实现音视频和互动白板，只预留接口，保证后续可无缝接入

---

## 1. 设计目标

1. **不实现，只预留**：本阶段只定义接口，不引入 mediasoup、不自研 SFU。
2. **接口稳定**：接口设计一次到位，后续实现不改调用方。
3. **解耦**：音视频、互动白板、白板内核三者解耦。
4. **可替换**：音视频提供者、互动提供者、传输层都可替换。
5. **复用现有库**：互动白板走现有 C++ / TCP / Socket.IO 库。
6. **音视频走 mediasoup**：预留 mediasoup 接入点。
7. **协作一致**：互动白板与白板协作共用 CRDT 和命令层。
8. **时间戳对齐**：音视频与白板时间戳对齐，支持回放。
9. **权限一致**：互动白板权限与白板权限一致。
10. **AI 可调用**：互动白板操作预留 Tool，后续 AI 可调用。

## 9. 时间戳对齐

### 9.1 目标

音视频与白板时间戳对齐，支持回放。

### 9.2 时间戳模型

```cpp
namespace wb {

struct SessionTimestamp {
  std::string sessionId;
  int64_t startTime;
  int64_t currentTime;
  int64_t elapsed;
};

struct TimedEvent {
  std::string id;
  std::string type;
  int64_t timestamp;
  int64_t elapsed;
  std::string dataJson;
};

}
```

### 9.3 对齐策略

- 所有事件带 `timestamp` 和 `elapsed`
- 以会话开始时间为基准
- 音视频使用同一时间基准
- 白板事件使用同一时间基准
- 回放时按 `elapsed` 排序

### 9.4 时钟同步

- 客户端与服务端定期同步时钟
- 使用 NTP 或自定义协议
- 误差 < 50ms

## 14. 权限与协作

### 14.1 权限

- 音视频权限：加入、发言、视频、共享、录制
- 互动白板权限：编辑、批注、控制、分组、投票
- 与白板权限一致
- 支持角色：Host、CoHost、Presenter、Participant、Viewer、Guest

### 14.2 协作

- 互动白板与白板协作共用 CRDT
- 音视频事件与白板事件分开
- 支持跟随视角
- 支持页面同步

### 14.3 时间戳

- 所有事件带时间戳
- 音视频与白板时间戳对齐
- 支持回放
