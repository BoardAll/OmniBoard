# 构建、打包与发布设计

- 文档版本：v1.1
- 状态：详细设计稿
- 所属文档：《Flutter + C++ 工程结构设计 v1.0》《Web 端方案设计 v1.0》
- 适用范围：Windows / macOS / Linux / Web
- 定位：定义白板软件多平台构建、打包、签名、发布、更新、回滚的完整流程
- v1.1 变更：
  1. Windows 不考虑 arm64，改为支持 x64 + x86（32 位）
  2. 去掉 CI/CD，改为本地构建 + 手动发布
  3. 补充本地构建环境准备

---

## 1. 设计目标

1. **一键构建**：一条命令构建所有平台。
2. **可重复**：相同源码构建出相同产物。
3. **本地构建**：不依赖 CI/CD，本地完成构建、打包、签名。
4. **多平台**：Windows / macOS / Linux / Web。
5. **Windows 多架构**：x64 + x86（32 位）。
6. **签名安全**：代码签名、公证、防篡改。
7. **增量更新**：桌面端支持增量更新。
8. **快速回滚**：发布后发现问题可快速回滚。
9. **可追溯**：每个产物可追溯到 commit。
10. **分发多样**：官网、应用商店、企业内部分发。

## 6. C++ 核心构建

### 6.1 构建流程

```text
1. 安装依赖
2. 配置 CMake
3. 编译 C++ 核心
4. 编译平台插件
5. 输出动态库 / 静态库 / WASM
6. 复制到 Flutter 项目
```

```bash
cmake --preset windows-x64
cmake --build build/windows-x64 --config Release
```

产物：

```text

  wb_core.dll
  wb_core.lib
  wb_core.pdb
```


## 8. 一键构建

### 8.1 构建脚本

`tools/scripts/build.sh`：

```bash
#!/bin/bash
set -e

VERSION=${WB_VERSION:-1.0.0}
BUILD_NUMBER=${WB_BUILD_NUMBER:-1}
PLATFORM=${1:-all}

build_core_windows_x64() {
  echo "Building C++ core for Windows x64..."
  cmake --preset windows-x64
  cmake --build build/windows-x64 --config Release
  cp build/windows-x64/Release/wb_core.dll apps/desktop/windows/runner/
}

build_core_windows_x86() {
  echo "Building C++ core for Windows x86..."
  cmake --preset windows-x86
  cmake --build build/windows-x86 --config Release
  cp build/windows-x86/Release/wb_core.dll apps/desktop/windows/runner32/
}

build_core_macos() {
  echo "Building C++ core for macOS..."
  cmake --preset macos-arm64
  cmake --build build/macos-arm64
  cp build/macos-arm64/libwb_core.dylib apps/desktop/macos/Frameworks/
}

build_core_linux() {
  echo "Building C++ core for Linux..."
  cmake --preset linux-x64
  cmake --build build/linux-x64
  cp build/linux-x64/libwb_core.so apps/desktop/linux/lib/
}

build_core_wasm() {
  echo "Building C++ core for WASM..."
  source $EMSDK/emsdk_env.sh
  emcmake cmake -B build/wasm -DWB_BUILD_WASM=ON -DCMAKE_BUILD_TYPE=Release
  cmake --build build/wasm
  cp build/wasm/wb_core.* apps/web/web/
}

build_app_windows_x64() {
  echo "Building Flutter Windows x64 app..."
  cd apps/desktop
  flutter build windows --release --build-name=$VERSION --build-number=$BUILD_NUMBER
  cd ../..
}

build_app_windows_x86() {
  echo "Building Flutter Windows x86 app..."
  cd apps/desktop
  flutter build windows --release --target-platform windows-x86 --build-name=$VERSION --build-number=$BUILD_NUMBER
  cd ../..
}

build_app_macos() {
  echo "Building Flutter macOS app..."
  cd apps/desktop
  flutter build macos --release --build-name=$VERSION --build-number=$BUILD_NUMBER
  cd ../..
}

build_app_linux() {
  echo "Building Flutter Linux app..."
  cd apps/desktop
  flutter build linux --release --build-name=$VERSION --build-number=$BUILD_NUMBER
  cd ../..
}

build_app_web() {
  echo "Building Flutter Web app..."
  cd apps/web
  flutter build web --release --wasm --build-name=$VERSION --build-number=$BUILD_NUMBER
  cd ../..
}

package_windows_x64() {
  echo "Packaging Windows x64 installer..."
  iscc tools/installer/windows/whiteboard-x64.iss
}

package_windows_x86() {
  echo "Packaging Windows x86 installer..."
  iscc tools/installer/windows/whiteboard-x86.iss
}

package_macos() {
  echo "Packaging macOS DMG..."
  create-dmg \
    --volname "Whiteboard" \
    --window-size 600 400 \
    --icon-size 100 \
    --app-drop-link 450 200 \
    "dist/Whiteboard-$VERSION.dmg" \
    "apps/desktop/build/macos/Build/Products/Release/whiteboard.app"
}

package_linux() {
  echo "Packaging Linux AppImage..."
  linuxdeploy --appdir AppDir \
    --executable apps/desktop/build/linux/x64/release/bundle/whiteboard \
    --output appimage
  mv Whiteboard*.AppImage dist/
}

package_web() {
  echo "Packaging Web..."
  tar -czf dist/whiteboard-web-$VERSION.tar.gz -C apps/web/build/web .
}

case $PLATFORM in
  windows)
    build_core_windows_x64
    build_app_windows_x64
    package_windows_x64
    build_core_windows_x86
    build_app_windows_x86
    package_windows_x86
    ;;
  windows-x64)
    build_core_windows_x64
    build_app_windows_x64
    package_windows_x64
    ;;
  windows-x86)
    build_core_windows_x86
    build_app_windows_x86
    package_windows_x86
    ;;
  macos)
    build_core_macos
    build_app_macos
    package_macos
    ;;
  linux)
    build_core_linux
    build_app_linux
    package_linux
    ;;
  web)
    build_core_wasm
    build_app_web
    package_web
    ;;
  all)
    build_core_windows_x64 && build_app_windows_x64 && package_windows_x64
    build_core_windows_x86 && build_app_windows_x86 && package_windows_x86
    build_core_macos && build_app_macos && package_macos
    build_core_linux && build_app_linux && package_linux
    build_core_wasm && build_app_web && package_web
    ;;
  *)
    echo "Unknown platform: $PLATFORM"
    exit 1
    ;;
esac

echo "Build complete!"
```


## 9. 代码签名

### 9.1 Windows 签名

工具：`signtool.exe`（Windows SDK）

```bash
signtool sign ^
  /f cert.pfx ^
  /p password ^
  /tr http://timestamp.digicert.com ^
  /td sha256 ^
  /fd sha256 ^
  /a ^
  whiteboard.exe

signtool sign ^
  /f cert.pfx ^
  /p password ^
  /tr http://timestamp.digicert.com ^
  /td sha256 ^
  /fd sha256 ^
  /a ^
  wb_core.dll
```

证书类型：

- EV 代码签名证书（推荐）
- OV 代码签名证书
- 自签名（仅测试）

x64 和 x86 都需要签名。

### 9.2 macOS 签名与公证

签名：

```bash
codesign --deep --force --verify --verbose \
  --sign "Developer ID Application: Example Inc (TEAMID)" \
  --options runtime \
  --entitlements entitlements.plist \
  whiteboard.app
```

公证：

```bash
xcrun notarytool submit Whiteboard-1.0.0.dmg \
  --apple-id "developer@example.com" \
  --team-id "TEAMID" \
  --password "app-specific-password" \
  --wait
```

装订：

```bash
xcrun stapler staple Whiteboard-1.0.0.dmg
xcrun stapler staple whiteboard.app
```

验证：

```bash
spctl --assess --verbose whiteboard.app
xcrun stapler validate whiteboard.app
```

### 9.3 Linux 签名

- GPG 签名 deb / rpm
- AppImage 签名

```bash
gpg --detach-sign --armor whiteboard_1.0.0_amd64.deb
gpg --detach-sign --armor whiteboard_1.0.0_amd64.rpm
```

### 9.4 Web 签名

- SRI（Subresource Integrity）
- CSP
- HTTPS

```html
<script src="main.dart.js"
  integrity="sha384-..."
  crossorigin="anonymous"></script>
```

## 16. 版本管理

### 16.1 版本号

遵循 SemVer：

```text
MAJOR.MINOR.PATCH+BUILD
1.0.0+123
```

- MAJOR：不兼容变更
- MINOR：新功能
- PATCH：修复
- BUILD：构建号

### 16.2 版本文件

`VERSION`：

```text
1.0.0
```

`pubspec.yaml`：

```yaml
version: 1.0.0+123
```

`CMakeLists.txt`：

```cmake
project(wb VERSION 1.0.0)
```

### 16.3 版本同步脚本

`tools/scripts/update_version.sh`：

```bash
#!/bin/bash
set -e

VERSION=$1
BUILD=${2:-1}

if [ -z "$VERSION" ]; then
  echo "Usage: ./update_version.sh <version> [build]"
  exit 1
fi

echo $VERSION > VERSION

sed -i "s/^version:.*/version: $VERSION+$BUILD/" apps/desktop/pubspec.yaml
sed -i "s/^version:.*/version: $VERSION+$BUILD/" apps/web/pubspec.yaml

sed -i "s/project(wb VERSION .*/project(wb VERSION $VERSION)/" core/CMakeLists.txt

echo "Version updated to $VERSION+$BUILD"
```
