# 透明批注模式技术方案

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.8》《齿轮圆盘交互详细设计 v1.1》《C++ 核心引擎接口设计 v1.0》
- 适用范围：Flutter UI + C++ 核心 + 平台插件
- 定位：透明批注模式是白板的“返回桌面”能力，白板窗口变透明，用户可在桌面上直接批注，同时可随时切回操作电脑

---

## 1. 设计目标

1. **返回桌面**：点击后白板窗口变透明，桌面和其他应用可见。
2. **两种状态**：穿透态操作电脑，批注态绘制批注。
3. **一键切换**：全局快捷键或悬浮工具栏切换。
4. **批注可保存**：退出时可将批注保存到白板。
5. **三端支持**：Windows / macOS / Linux X11 完整支持，Linux Wayland 降级。
6. **不干扰操作**：穿透态下鼠标事件完全传给系统。
7. **视觉克制**：工具栏固定在右上角，不遮挡桌面内容。
8. **性能低延迟**：批注绘制跟手，不阻塞系统。
9. **安全合规**：屏幕内容涉及隐私，需明确授权。
10. **与圆盘一致**：透明批注模式下圆盘隐藏，使用专用工具栏；退出后圆盘恢复。

## 3. 窗口设计

### 3.1 两个窗口

| 窗口 | 作用 | 鼠标行为 |
|---|---|---|
| 覆盖层窗口 | 全屏透明，承载批注层 | 穿透态：穿透；批注态：捕获 |
| 悬浮工具栏窗口 | 右上角工具栏 | 始终可点击，不穿透 |

### 3.2 覆盖层窗口

- 全屏，覆盖所有显示器或主显示器
- 透明背景
- 无边框
- 始终置顶
- 不显示在任务栏
- 支持多显示器坐标

### 3.3 悬浮工具栏窗口

- 固定右上角
- 始终置顶
- 不穿透
- 可拖拽位置
- 可折叠为小胶囊
- 按钮固定，不支持自定义

### 3.4 窗口层级

```text
桌面 / 其他应用
  ↓
覆盖层窗口（透明，批注层）
  ↓
悬浮工具栏窗口（不透明，可点击）
```

## 4. 两种状态

### 4.1 穿透态

- 鼠标事件传给系统
- 用户可正常操作电脑
- 批注层不接收鼠标事件
- 工具栏仍可点击
- 工具栏中 🖱️ 按钮高亮

### 4.2 批注态

- 鼠标事件被白板捕获
- 用户可绘制批注
- 工具栏中 ✏️ 按钮高亮
- 按住 `Alt` 临时穿透
- 松开 `Alt` 恢复批注

### 4.3 状态切换

| 操作 | 行为 |
|---|---|
| 点击 🖱️ | 切换到穿透态 |
| 点击 ✏️ | 切换到批注态 |
| `Alt + Shift + A` | 全局切换穿透 / 批注 |
| 按住 `Alt` | 批注态临时穿透 |
| 点击 ✕ | 退出透明批注模式 |

## 7. 平台实现

### 7.1 Windows

窗口透明：

```cpp
SetWindowLong(hwnd, GWL_EXSTYLE,
  GetWindowLong(hwnd, GWL_EXSTYLE) | WS_EX_LAYERED | WS_EX_TRANSPARENT);
```

穿透切换：

```cpp
// 穿透态
SetWindowLong(hwnd, GWL_EXSTYLE,
  GetWindowLong(hwnd, GWL_EXSTYLE) | WS_EX_TRANSPARENT);

// 批注态
SetWindowLong(hwnd, GWL_EXSTYLE,
  GetWindowLong(hwnd, GWL_EXSTYLE) & ~WS_EX_TRANSPARENT);
```

置顶：

```cpp
SetWindowPos(hwnd, HWND_TOPMOST, 0, 0, 0, 0,
  SWP_NOMOVE | SWP_NOSIZE | SWP_NOACTIVATE);
```

DWM 透明：

- 使用 `DwmExtendFrameIntoClientArea`
- 或设置 `WS_EX_LAYERED` + `SetLayeredWindowAttributes`

多显示器：

- 使用虚拟屏幕坐标 `SM_XVIRTUALSCREEN`、`SM_YVIRTUALSCREEN`
- 覆盖所有显示器

### 7.2 macOS

窗口透明：

```objc
[window setOpaque:NO];
[window setBackgroundColor:[NSColor clearColor]];
[window setLevel:NSFloatingWindowLevel];
[window setCollectionBehavior:
  NSWindowCollectionBehaviorCanJoinAllSpaces |
  NSWindowCollectionBehaviorFullScreenAuxiliary];
```

穿透切换：

```objc
// 穿透态
[window setIgnoresMouseEvents:YES];

// 批注态
[window setIgnoresMouseEvents:NO];
```

置顶：

```objc
[window setLevel:NSScreenSaverWindowLevel];
```

多显示器：

- 使用 `NSScreen.screens`
- 覆盖所有屏幕或主屏幕

权限：

- 透明覆盖不需要屏幕录制权限
- 截图批注需要屏幕录制权限

### 7.3 Linux X11

窗口透明：

- 使用合成器（Compositor）
- 设置 `_NET_WM_WINDOW_TYPE_DOCK` 或 `_NET_WM_WINDOW_TYPE_NOTIFICATION`
- 设置 `_NET_WM_STATE_ABOVE`

穿透切换：

- 使用 XShape 设置输入区域
- 或使用 `Xinput2` 重定向

置顶：

- `_NET_WM_STATE_ABOVE`

多显示器：

- 使用 Xinerama 或 RandR
- 覆盖所有屏幕

依赖：

- 需要合成器支持透明
- 不同桌面环境行为可能不同

### 7.4 Linux Wayland

限制：

- 输入穿透支持不统一
- 需要 layer-shell 协议
- 部分合成器不支持

降级方案：

- 非全屏批注窗口
- 手动切换穿透 / 批注
- 不覆盖所有屏幕

### 7.5 平台兼容矩阵

| 能力 | Windows | macOS | Linux X11 | Linux Wayland |
|---|---|---|---|---|
| 透明覆盖 | ✅ | ✅ | ✅ | ⚠️ |
| 鼠标穿透 | ✅ | ✅ | ⚠️ | ❌/降级 |
| 全局快捷键 | ✅ | ✅ | ✅ | ⚠️ |
| 多显示器 | ✅ | ✅ | ✅ | ⚠️ |

### 11.2 状态机

```cpp
enum class TransparentState {
  Inactive,     // 未进入
  Entering,     // 进入中
  Penetrating,  // 穿透态
  Annotating,   // 批注态
  Exiting,      // 退出中
};

class TransparentMode {
public:
  void enter();
  void exit();

  void setPenetrate(bool penetrate);
  bool isPenetrating() const;

  void toggleMode();
  void temporaryPenetrate(bool enable);

  TransparentState getState() const;

  void saveToBoard();
  void discard();
  void keep();

private:
  TransparentState state_ = TransparentState::Inactive;
  AnnotationLayer annotationLayer_;
  std::mutex mutex_;
};
```

### 11.3 批注层

```cpp
struct AnnotationStroke {
  std::string id;
  std::vector<Point> points;
  Color color;
  float width;
  float opacity;
  std::string brushType;
  std::vector<float> pressure;
  Timestamp timestamp;
};

class AnnotationLayer {
public:
  std::string addStroke(const AnnotationStroke& stroke);
  void removeStroke(const std::string& id);
  void clear();

  void undo();
  void redo();

  std::vector<AnnotationStroke> listStrokes() const;

  std::string toJson() const;
  void fromJson(const std::string& json);

  void saveToBoard(const PageId& pageId);

private:
  std::vector<AnnotationStroke> strokes_;
  std::vector<AnnotationStroke> redoStack_;
  std::mutex mutex_;
};
```

## 13. 性能与优化

### 13.1 性能目标

| 指标 | 目标 |
|---|---|
| 批注延迟 | < 16ms |
| 批注帧率 | 60fps |
| 透明窗口合成 | 60fps |
| 内存占用 | < 100MB |
| 进入 / 退出 | < 200ms |

### 13.2 优化策略

- 覆盖层窗口使用 GPU 合成
- 批注层独立渲染
- 只重绘脏区域
- 批注路径简化
- 低延迟输入处理
- 多显示器按需渲染

### 13.3 边界情况

- 多显示器：覆盖所有屏幕
- 高 DPI：按 DPI 缩放
- 全屏应用：置顶层级足够高
- 系统弹窗：不遮挡
- 屏幕锁定：自动退出
- 性能不足：降低批注采样率
