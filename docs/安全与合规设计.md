- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.5》《C++ 核心引擎接口设计 v1.0》《Open API 规范 v1.0》《MCP Server 详细设计 v1.0》《测试方案设计 v1.0》
- 适用范围：Windows x64 / x86、macOS、Linux、Web
- 定位：定义白板软件在认证、授权、数据、通信、AI、MCP、API、供应链、合规等方面的安全设计

---

## 1. 设计目标

1. **默认安全**：所有功能默认安全配置，用户无需额外操作。
2. **权限一致**：用户、AI、Open API、MCP 使用同一套权限模型。
3. **最小权限**：只授予必要权限，Scope 细粒度。
4. **数据可控**：数据不训练、可导出、可删除。
5. **传输加密**：所有网络通信 HTTPS / WSS。
6. **存储加密**：敏感数据加密存储。
7. **审计完整**：所有关键操作可追溯。
8. **多租户隔离**：企业数据物理或逻辑隔离。
9. **合规可验证**：支持 GDPR、SOC 2、ISO 27001。
10. **私有化可选**：企业可私有化部署，数据不出内网。

## 3. 认证

### 3.1 认证方式

| 方式 | 适用场景 | 说明 |
|---|---|---|
| OAuth 2.0 | 第三方应用 | Authorization Code + PKCE |
| API Key | 服务端集成 | Header 传递 |
| JWT | 内部服务 | 签名验证 |
| SSO | 企业 | SAML / OIDC |
| 邮箱 + 密码 | 个人 | 密码哈希 |
| 手机号 + 验证码 | 个人 | 短信验证 |
| 第三方登录 | 个人 | Google / Apple / 微信 |
| 生物识别 | 客户端 | Touch ID / Windows Hello |

### 3.2 密码策略

| 项 | 要求 |
|---|---|
| 最小长度 | 8 |
| 最大长度 | 128 |
| 复杂度 | 大小写 + 数字 + 特殊字符 |
| 哈希算法 | Argon2id |
| 盐 | 随机 16 字节 |
| 迭代 | Argon2id 默认参数 |
| 历史密码 | 不可重复最近 5 次 |
| 失败锁定 | 5 次失败锁定 15 分钟 |
| 过期 | 可选，企业可配置 |
| 重置 | 邮箱 / 短信验证 |
