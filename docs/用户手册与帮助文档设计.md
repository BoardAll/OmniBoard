# 用户手册与帮助文档设计

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.5》《齿轮圆盘交互详细设计 v1.1》《左侧栏与页面管理设计 v1.0》
- 适用范围：Windows x64 / x86、macOS、Linux、Web
- 定位：定义白板软件的用户手册、帮助文档、新手引导、内置帮助、FAQ、视频教程、多语言、反馈机制

---

## 1. 设计目标

1. **低门槛**：新用户 5 分钟内上手。
2. **分层**：新手引导、快速上手、完整手册、进阶技巧、FAQ。
3. **多入口**：内置帮助、官网文档、视频教程、社区。
4. **多语言**：中文、英文优先，后续扩展。
5. **可搜索**：全局搜索，快速定位。
6. **可离线**：内置帮助离线可用。
7. **可更新**：文档随版本更新。
8. **可反馈**：用户可反馈文档问题。
9. **无障碍**：支持屏幕阅读器、高对比度。
10. **AI 友好**：AI 助手可回答用户问题，引用文档。

### 3.2 交互式引导

分步骤引导：

```text
步骤 1：认识圆盘
  - 高亮圆盘
  - 提示“点击圆盘展开工具”
  - 用户点击后继续

步骤 2：创建便签
  - 高亮便签工具
  - 提示“选择便签，点击画布创建”
  - 用户创建后继续

步骤 3：编辑便签
  - 高亮便签
  - 提示“双击编辑，Tab 创建下一个”
  - 用户编辑后继续

步骤 4：创建连线
  - 高亮连接点
  - 提示“拖拽连接点创建连线”
  - 用户连线后继续

步骤 5：使用 AI
  - 高亮 AI 图标
  - 提示“点击 AI，输入指令”
  - 用户尝试后继续

步骤 6：页面管理
  - 高亮左侧栏
  - 提示“点击页面管理”
  - 用户查看后继续

步骤 7：完成
  - 显示“引导完成”
  - 提供快捷键卡片
  - 提供示例白板
```

## 4. 快速上手

### 4.1 5 分钟上手

```markdown
# 5 分钟上手白板

## 1. 打开圆盘
点击右下角齿轮圆盘，展开工具。

## 2. 创建便签
选择便签工具，点击画布创建。

## 3. 编辑便签
双击便签编辑，Tab 创建下一个。

## 4. 创建连线
拖拽便签边缘连接点，拉出连线。

## 5. 使用 AI
点击左侧栏 AI 图标，输入指令。

## 6. 切换页面
点击左侧栏页面，查看缩略图。

## 7. 分享白板
点击左侧栏顶部菜单，分享链接。

## 8. 返回桌面
点击左侧栏菜单，返回桌面批注。
```

### 7.2 故障排查

```markdown
# 故障排查

## 白板卡顿
- 检查元素数量
- 关闭不必要的 3D 元素
- 降低渲染质量
- 清理缓存

## 无法打开白板
- 检查网络
- 检查权限
- 检查版本
- 重启应用

## AI 无响应
- 检查网络
- 检查账号
- 检查配额
- 重试

## 语音无法识别
- 检查麦克风权限
- 检查网络
- 切换语言
- 重试

## 透明批注无法使用
- 检查系统版本
- 检查权限
- Linux Wayland 不支持完整功能

## 3D 渲染异常
- 检查显卡驱动
- 检查 WebGL2 支持
- 降级渲染
- 重启应用

## Web 端无法加载
- 检查浏览器版本
- 检查网络
- 清理缓存
- 检查 WASM 支持

## 同步延迟
- 检查网络
- 检查服务器状态
- 重试

## 导出失败
- 检查元素数量
- 检查磁盘空间
- 重试
```
