# 白板软件设计文档 v0.8  
## UI 交互最终确认版：纯圆盘 + 左侧栏 + 页面管理

- 文档版本：v0.8
- 状态：UI 交互确认稿
- 基础技术栈：Flutter + C++ 核心 + 云端 AI + MCP（沿用 v0.5）
- 本次确认：
  1. 完全靠圆盘，去掉顶部栏
  2. 左侧栏需要
  3. 页面管理从左侧打开
  4. 不需要 Dock
  5. 3D 选色后点表面，不需要“应用到所有面”快捷键
  6. 不需要独立函数列表面板
  7. 流程图自动布局支持手动微调
  8. 泳道图是流程图的一部分
  9. 透明批注工具栏不支持自定义按钮
  10. 圆盘不支持用户自定义扇区

## 2. 齿轮圆盘（唯一工具入口）

### 2.1 形态

```text
                        便签
                         📝
                  ┌─────────────┐
                  │             │
          文本    │    齿轮     │   形状
           T      │     ⚙️      │    ▭
                  │             │
                  └─────────────┘
          连线                     图片
           →                       🖼️
                  ┌─────────────┐
                  │             │
          画笔    │   更多      │   导图
           ✏️     │    ⋯        │    🧠
                  │             │
                  └─────────────┘
                        表格
                         ⊞
```

- 中心：齿轮图标，显示当前工具
- 内环：6 个常用工具
- 外环：8 个分组
- 点击中心展开/收起
- 长按画布临时弹出
- 锁定常驻右下角
- 不支持用户自定义扇区

### 2.2 内环 / 外环

| 内环 | 外环分组 |
|---|---|
| 选择 | 选择 / 手 |
| 便签 | 便签 / 文本 |
| 形状 | 形状 / 连线 |
| 画笔 | 画笔 / 橡皮 |
| 图片 | 图片 / 文档 |
| 更多 | 导图 / 表格 / 函数 / 3D / 2D / 流程图 / AI / 设置 |

### 2.3 交互

| 操作 | 行为 |
|---|---|
| 点击中心 | 展开/收起 |
| 从中心向外拖动 | 滑到扇区松开即选中 |

### 3.3 操作

| 操作 | 方式 |
|---|---|
| 新建 | 顶部 `+` |
| 复制 | 右键 / 悬停 |
| 删除 | 右键 / 悬停，可撤销 |
| 移动 | 拖拽排序 |
| 重命名 | 双击 |
| 锁定 | 右键 |
| 隐藏 | 右键 |

- 编辑停止 500ms 后刷新

- 视口外不实时渲染
- 手动刷新按钮

## 5. 透明批注工具栏（右上角）

### 5.1 位置

固定右上角，不可自定义按钮。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                    ┌──────────────────────┐  │
│                                                    │ ✏️ 🧽 │ ▭ → T │ ↶ ↷ │  │
│                                                    │ 🖱️ │ 🎨 │ ✕ │        │  │
│                                                    └──────────────────────┘  │
│                                                                              │
│                      桌面 / 其他应用可见                                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 内容

| 按钮 | 功能 |
|---|---|
| ✏️ | 画笔 |
| 🧽 | 橡皮 |
| ▭ | 形状 |
| → | 箭头 |
| T | 文字 |
| ↶ ↷ | 撤销/重做 |
| 🖱️ | 穿透态切换 |
| 🎨 | 颜色 |
| ✕ | 退出 |

### 5.3 交互

- 工具栏始终可点击，不穿透
- 可拖拽位置，但按钮固定
- 可折叠为小胶囊
- 全局快捷键 `Alt+Shift+A` 切换穿透/批注
- 批注态按住 `Alt` 临时穿透
- 退出时选择：保存到白板 / 丢弃 / 继续保留

## 6. 可扩展工具栏

### 6.1 设计原则

- 工具通过 `ToolRegistry` 注册
- 选中对象后，上下文工具栏根据对象类型动态变化
- 支持工具间联动：先选颜色，再点表面
- 不支持用户自定义按钮
- 不支持用户自定义圆盘扇区

### 6.2 3D 工具栏

选中 3D 元素后：

```text
┌──────────────────────────────────────────────────────────────┐
│ 🎨 颜色 │ 🧱 材质 │ 💡 光照 │ 🔄 旋转 │ 📐 尺寸 │ 📷 截图 │ ⋯ │
└──────────────────────────────────────────────────────────────┘
```

**选色后点表面：**

```text
1. 点击 🎨 颜色
2. 弹出调色板
3. 选择颜色
4. 光标变为“油漆桶”
5. 鼠标悬停在 3D 表面上，表面高亮
6. 点击表面，该表面上色
7. 实时生效
8. 按 Esc 退出上色模式
```

- 悬停表面描边高亮
- 当前选中表面持续高亮
- 支持 Shift + 点击多选表面
- 不支持“应用到所有面”快捷键

### 6.3 函数工具栏

选中函数元素后：

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 🎨 颜色 │ 〜 线型 │ 📏 线宽 │ ⚙️ 参数 │ 🔍 分析 │ + 函数 │ ⋯ │
└──────────────────────────────────────────────────────────────────────┘
```

- 点击颜色，当前函数曲线实时变色
- 点击线型，选择实线、虚线、点线、点划线，实时生效
- 点击线宽，调整 1–8px
- 点击 `+ 函数`，在同一坐标系添加新函数
- 点击分析，显示交点、零点、极值、导数、积分
- 不需要独立函数列表面板，所有函数操作通过上下文工具栏和画布元素完成

### 6.4 2D 工具栏

## 7. 流程图

### 7.1 定位

流程图是白板核心场景，泳道图是流程图的一部分。

### 7.2 元素

| 元素 | 形状 |
|---|---|
| 开始/结束 | 圆角矩形 / 椭圆 |
| 处理 | 矩形 |
| 判断 | 菱形 |
| 输入/输出 | 平行四边形 |
| 文档 | 波浪底矩形 |
| 数据库 | 圆柱 |
| 手动操作 | 梯形 |
| 连接点 | 圆 |
| 注释 | 开放矩形 |

### 7.3 快速创建

- 选中形状，拖拽边缘连接点拉出连线
- 连线末端自动创建新形状
- 按 Tab 创建下一个节点
- 按 Enter 创建分支
- 支持快捷形状：开始、处理、判断、结束

### 7.4 自动布局 + 手动微调

- 一键整理流程图
- 支持从上到下、从左到右
- 支持泳道图
- 自动对齐和分布
- **支持手动微调**：自动布局后，可拖拽单个节点微调位置，连线自动跟随

### 7.5 泳道图

- 是流程图的一部分
- 支持添加/删除泳道
- 支持横向/纵向
- 元素自动归属泳道

### 7.6 连线

- 直线、折线、曲线
- 箭头样式：实心、空心、开放
- 连线标签
- 连线自动避让
- 连线吸附锚点

### 7.7 模板

- 基础流程图
- 泳道图
- 用户旅程
- 状态机
- 数据流图
- 架构图

### 7.8 AI 调用

```text
“帮我画一个用户登录流程图”
→ flowchart.create

“把这个流程改成泳道图”
→ flowchart.toSwimlane

“自动整理这个流程图”
→ flowchart.autoLayout

“给判断节点加上是/否标签”
→ flowchart.labelBranches
```
