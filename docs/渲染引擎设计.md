# 渲染引擎设计（2D / 3D / 函数）

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.5》《C++ 核心引擎接口设计 v1.0》《可扩展工具栏设计 v1.0》
- 适用范围：Flutter UI + C++ 核心 + 云端 AI + MCP
- 定位：渲染引擎负责白板所有可视化内容的渲染，包括 2D、3D、函数、文档、视频合成

---

## 1. 设计目标

1. **高性能**：白板 60fps，3D 60fps，1000 元素不掉帧。
2. **分层渲染**：背景、静态、动态、3D、函数、视频、批注、UI 独立层。
3. **增量更新**：脏矩形 + 视口裁剪 + 缓存。
4. **跨平台**：Win / macOS / Linux / Web (WASM) 一套代码。
5. **GPU 加速**：2D 用 Skia/Impeller，3D 用 bgfx/Diligent。
6. **实时交互**：3D 旋转、函数缩放、表面选色实时生效。
7. **可扩展**：新渲染类型通过 RenderModel 注册。
8. **AI 可调用**：所有渲染操作有对应 Tool。
9. **可导出**：2D 导出 SVG/PNG，3D 导出 glTF/OBJ，函数导出 SVG。
10. **内存可控**：纹理缓存、对象池、LRU 淘汰。

## 3. 分层渲染

### 3.1 渲染层

```cpp
enum class RenderLayer {
  Background   = 0,  // 背景、网格、点阵
  Static       = 1,  // 图片、PDF 页、嵌入文档
  Dynamic      = 2,  // 形状、连线、文本、便签
  Render3D     = 3,  // 3D 场景
  Render2D     = 4,  // 2D 几何、图表
  Function     = 5,  // 函数图
  Video        = 6,  // 视频、屏幕共享
  Annotation   = 7,  // 批注层
  Selection    = 8,  // 选中框、连接点
  Cursor       = 9,  // 协作光标
  UI           = 10, // 工具栏、面板
};
```

### 3.2 分层策略

| 层 | 更新频率 | 缓存 | 渲染方式 |
|---|---|---|---|
| Background | 低 | 纹理 | Canvas 2D |
| Static | 低 | 纹理 | Canvas 2D |
| Dynamic | 高 | 局部缓存 | Canvas 2D |
| Render3D | 中 | 纹理 | bgfx 离屏 |
| Render2D | 中 | 局部缓存 | Canvas 2D |
| Function | 中 | 路径缓存 | Canvas 2D |
| Video | 高 | 原生纹理 | 原生 `<video>` / 纹理 |
| Annotation | 高 | 无 | Canvas 2D |
| Selection | 高 | 无 | Canvas 2D |
| Cursor | 高 | 无 | Canvas 2D |
| UI | 中 | 无 | Flutter Widget |

### 3.3 合成顺序

```text
Background
  → Static
    → Dynamic
      → Render3D
        → Render2D
          → Function
            → Video
              → Annotation
                → Selection
                  → Cursor
                    → UI
```

## 7. 3D 渲染

### 7.1 技术选型

- **bgfx**：轻量、跨平台、API 简洁
- **Diligent Engine**：功能强、支持 D3D12/Vulkan/Metal
- 备选：自研 OpenGL / Vulkan

推荐：**bgfx**，理由是轻量、跨平台、社区活跃。

### 7.2 渲染流程

```text
1. 构建场景图
2. 设置相机和光照
3. 提交渲染命令
4. 离屏渲染到纹理
5. Flutter 用 Texture Widget 显示
```

## 14. 性能优化

### 14.1 策略

## 16. 平台适配

### 16.1 图形 API

| 平台 | 2D | 3D |
|---|---|---|
| Windows | Skia / Impeller | bgfx (D3D11/12) |
| macOS | Skia / Impeller | bgfx (Metal) |
| Linux | Skia / Impeller | bgfx (Vulkan/OpenGL) |
| Web | Skia (CanvasKit) | WebGL2 / WebGPU |
| iOS | Skia / Impeller | bgfx (Metal) |
| Android | Skia / Impeller | bgfx (Vulkan/OpenGL) |

### 16.2 Web (WASM)

- C++ 编译为 WASM
- bgfx 编译到 WASM
- 使用 WebGL2 / WebGPU
- 2D 用 Canvas2D 或 WebGL
- 性能降级可接受
- 后续如不达标，独立实现 Web 渲染层

### 16.3 纹理共享

- C++ 渲染到共享纹理
- Flutter 用 `Texture` Widget 显示
- 桌面端用平台纹理共享 API
- Web 端用 WebGL 纹理
