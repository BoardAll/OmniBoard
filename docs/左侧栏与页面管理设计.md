# 左侧栏与页面管理设计

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.8》《齿轮圆盘交互详细设计 v1.1》
- 适用范围：Flutter UI + C++ 核心 + 云端 AI + MCP
- 定位：左侧栏是白板的第二入口，负责页面、图层、AI、设置；圆盘负责创作工具

---

## 1. 设计目标

1. **第二入口**：圆盘负责创作工具，左侧栏负责结构性内容。
2. **常驻可折叠**：默认展开 240px，可折叠为 56px。
3. **分区清晰**：标题、页面、图层、AI、设置五个分区。
4. **页面管理为主**：页面是左侧栏的核心，支持缩略图、复制、删除、移动。
5. **不遮挡内容**：折叠后只保留图标，不占用画布空间。
6. **协作可见**：显示成员所在页面，支持跟随。
7. **可扩展**：插件可注册新的左侧栏分区。
8. **不替代圆盘**：圆盘仍是唯一创作工具入口。

- 页面切换时刷新

- 手动刷新按钮
- 缩略图分辨率按卡片大小自适应

## 8. 协作设计

### 8.1 成员状态

- 每个成员有独立颜色
- 颜色用于光标、选区、页面标记
- 成员列表显示在线状态
- 显示当前所在页面

### 8.2 页面协作

- 页面缩略图右上角显示成员头像小点
- 点击可跳转到该成员所在页面
- 支持“跟随”模式，视角同步
- 页面锁：防止同时移动同一页

### 8.3 评论

- 页面有未读评论时显示小红点
- 点击打开评论面板
- 支持按页面筛选评论

### 8.4 冲突处理

- 页面增删改走 CRDT
- 同时移动页面时，以最后操作为准
- 删除页面时，提示其他成员
- 页面锁避免冲突

## 11. 边界情况

### 11.1 页面数量多

- 页面超过 50 个时，启用虚拟化
- 只渲染可见卡片
- 缩略图懒加载
- 支持搜索页面

### 11.2 缩略图加载

- 缩略图未生成时显示骨架屏
- 缩略图生成失败显示默认图
- 支持手动刷新
- 缩略图缓存到本地

### 11.3 小屏幕

- 屏幕宽度 < 1024px 时，左侧栏默认折叠
- 折叠后悬停临时展开
- 点击后固定展开

### 11.4 多显示器

- 左侧栏跟随主窗口
- 跨屏拖动时位置正确
- 每个窗口独立状态

### 11.5 性能

- 左侧栏使用独立渲染层
- 缩略图后台渲染
- 列表虚拟化
- 图标预加载
- 拖拽排序使用 GPU 合成

→ page.move

→ page.list + ai.summarize

“把第 1 页的流程图拆成 3 页”
→ page.split

“把第 2 页和第 3 页合并”
→ page.merge
