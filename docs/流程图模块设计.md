# 流程图模块设计

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.8》《齿轮圆盘交互详细设计 v1.1》《左侧栏与页面管理设计 v1.0》《可扩展工具栏设计 v1.0》
- 适用范围：Flutter UI + C++ 核心 + 云端 AI + MCP
- 定位：流程图是白板核心场景之一，支持标准流程图、泳道图、自动布局与手动微调

---

## 1. 设计目标

1. **标准流程图**：支持开始、处理、判断、输入输出等标准元素。
2. **快速创建**：拖拽连线自动创建节点，Tab / Enter 快速添加。
3. **自动布局**：一键整理，支持从上到下、从左到右。
4. **手动微调**：自动布局后可拖拽单个节点，连线自动跟随。
5. **泳道图**：作为流程图的一部分，支持横向/纵向泳道。
6. **连线智能**：自动避让、吸附锚点、支持折线/曲线。
7. **模板丰富**：内置多种流程图模板。
8. **AI 可调用**：所有流程图操作都有对应 Tool，AI 可生成、修改、整理。
9. **与工具栏集成**：选中流程图元素后显示专用上下文工具栏。

## 3. 数据模型

### 3.1 流程图元素

```cpp
enum class FlowchartNodeType {
  Start,          // 开始
  End,            // 结束
  Process,        // 处理
  Decision,       // 判断
  InputOutput,    // 输入/输出
  Document,       // 文档
  Database,       // 数据库
  ManualOperation,// 手动操作
  Connector,      // 连接点
  Annotation,     // 注释
  Swimlane,       // 泳道
  Custom          // 自定义
};

struct FlowchartNode {
  std::string id;
  FlowchartNodeType type;
  std::string text;
  Rect bounds;
  std::string styleId;
  std::string swimlaneId;
  std::vector<std::string> incoming;
  std::vector<std::string> outgoing;
  bool locked;
  bool hidden;
};

struct FlowchartConnector {
  std::string id;
  std::string fromNodeId;
  std::string toNodeId;
  std::string fromAnchor;
  std::string toAnchor;
  ConnectorStyle style;      // 直线 / 折线 / 曲线
  ArrowStyle arrowStart;
  ArrowStyle arrowEnd;
  std::string label;
  std::vector<Point> waypoints;
  bool autoRoute;
};

struct Swimlane {
  std::string id;
  std::string name;
  float position;
  float size;
  Orientation orientation;   // Horizontal / Vertical
  std::string color;
};

struct Flowchart {
  std::string id;
  std::vector<FlowchartNode> nodes;
  std::vector<FlowchartConnector> connectors;
  std::vector<Swimlane> swimlanes;
  LayoutDirection direction; // TopToBottom / LeftToRight
  std::string templateId;
};
```

### 3.2 元素形状

| 类型 | 形状 |
|---|---|
| Start | 圆角矩形 / 椭圆 |
| End | 圆角矩形 / 椭圆 |
| Process | 矩形 |
| Decision | 菱形 |
| InputOutput | 平行四边形 |
| Document | 波浪底矩形 |
| Database | 圆柱 |
| ManualOperation | 梯形 |
| Connector | 圆 |
| Annotation | 开放矩形 |

- 形状：圆角矩形或椭圆

- 连接点：底部或右侧

### 4.2 处理

- 形状：矩形
- 文本：动作描述

### 4.3 判断

- 形状：菱形
- 文本：条件
- 颜色：橙色
- 分支：是 / 否，默认标签
- 连接点：四边

### 4.4 输入 / 输出

- 形状：平行四边形
- 文本：输入或输出内容
- 颜色：紫色

- 形状：波浪底矩形
- 文本：文档名称
- 颜色：灰色

- 形状：圆柱

- 形状：梯形

- 形状：圆

## 7. 自动布局

### 7.1 布局方向

| 方向 | 说明 |
|---|---|
| 从上到下 | 默认，适合大多数流程 |
| 从左到右 | 适合横向流程 |
| 从下到上 | 可选 |
| 从右到左 | 可选 |

### 7.2 布局算法

- 基于分层布局（Sugiyama 风格）
- 步骤：
  1. 构建有向图
  2. 检测环
  3. 分层
  4. 减少交叉
  5. 分配坐标
  6. 路由连线
- 支持泳道约束
- 支持节点大小约束

### 7.3 自动布局参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 水平间距 | 80px | 同层节点间距 |
| 垂直间距 | 60px | 层间距 |
| 节点对齐 | 居中 | 左/中/右 |
| 连线风格 | 折线 | 直线/折线/曲线 |
| 避让距离 | 20px | 连线与节点距离 |

### 7.4 手动微调

- 自动布局后，可拖拽单个节点
- 拖拽时连线自动跟随
- 支持锁定节点位置
- 支持“重新布局”恢复自动结果
- 支持“部分布局”：只整理选中节点

### 7.5 自动布局工具 ID

| 操作 | 工具 ID |
|---|---|
| 自动布局 | flowchart.autoLayout |
| 部分布局 | flowchart.partialLayout |
| 重新布局 | flowchart.relayout |
| 锁定节点 | flowchart.lockNode |

## 14. AI 调用

### 14.1 生成流程图

```text
“帮我画一个用户登录流程图”
→ flowchart.create

“生成一个订单审批流程，包含提交、审批、通过、驳回”
→ flowchart.create + flowchart.autoLayout

“把这段文字转成流程图”
→ flowchart.create + ai.parseText
```

### 14.2 修改流程图

```text
“在判断节点后面加上‘通知用户’”
→ flowchart.addNode + flowchart.connect

“把‘是’分支改成‘同意’”
→ flowchart.updateConnector + flowchart.setLabel

“把这个流程改成泳道图”
→ flowchart.toSwimlane

“自动整理这个流程图”
→ flowchart.autoLayout

“给判断节点加上是/否标签”
→ flowchart.labelBranches
```

### 14.3 分析流程图

```text
“找出这个流程图的死循环”
→ flowchart.analyze

“总结这个流程图的步骤”
→ flowchart.analyze + ai.summarize

“检查这个流程图有没有缺少结束节点”
→ flowchart.validate
```

- 流程图节点高亮

- 侧栏显示执行卡片
- 完成后可撤销
- 批量操作合并为一个事务
