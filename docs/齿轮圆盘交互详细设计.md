## 1. 设计目标

1. **唯一入口**：所有创作工具从圆盘进入，不依赖顶部栏。
2. **不遮挡内容**：常驻右下角，可锁定、可隐藏、可临时弹出。
3. **快速切换**：单击、拖拽、双击三种方式都能选中工具。
4. **层级清晰**：内环常用、外环分组、子环展开，最多两层。
5. **触屏友好**：支持手指、手写笔、鼠标三种输入。
6. **可扩展**：新工具通过 ToolRegistry 注册，自动出现在圆盘。
7. **不可自定义**：扇区固定，不支持用户编辑，保证一致性。
8. **最近使用**：内环固定 6 个，最近使用单独显示。
9. **轨迹反馈**：拖拽选中时显示轨迹线和高亮。

## 2. 圆盘结构

### 2.1 三层结构

```text
┌─────────────────────────────────────────────┐
│  外环（8 分组）                             │
│    ┌───────────────────────────────────┐    │
│    │  内环（6 常用工具）               │    │
│    │    ┌─────────────────────────┐    │    │
│    │    │  中心（齿轮 + 当前工具）│    │    │
│    │    └─────────────────────────┘    │    │
│    └───────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

| 层 | 数量 | 半径 | 内容 |
|---|---|---|---|
| 中心 | 1 | 0–28px | 齿轮图标 + 当前工具 |
| 内环 | 6 | 28–72px | 常用工具，固定 |
| 外环 | 8 | 72–120px | 工具分组，固定 |
| 子环 | 动态 | 120–180px | 分组展开后的子工具，可滚动 |
| 最近使用 | 最多 3 | 中心下方 | 最近使用工具快捷条 |

### 2.2 尺寸

| 项 | 尺寸 |
|---|---|
| 圆盘总直径 | 240px（收起 56px） |
| 中心圆 | 56px |
| 内环扇区 | 44px 宽 |
| 外环扇区 | 48px 宽 |
| 子工具扇区 | 44px 宽 |
| 图标 | 24px |
| 标签字号 | 11px |
| 扇区间隙 | 2px |
| 最近使用图标 | 28px |

### 2.3 位置

- 默认右下角
- 距右边 24px，距底边 24px
- 迷你地图在圆盘上方，间距 16px
- 圆盘展开时，迷你地图不隐藏
- 若空间不足，圆盘自动向左上展开，避免遮挡迷你地图
- 锁定后可拖拽到其他角落
- 支持四角吸附：左上、右上、左下、右下

## 5. 交互手势

### 5.1 手势总表

| 手势 | 行为 | 触发区域 |
|---|---|---|
| 单击中心 | 展开 / 收起圆盘 | 中心圆 |
| 单击内环扇区 | 选中该工具，圆盘收起 | 内环扇区 |
| 单击外环扇区 | 展开该分组的子工具 | 外环扇区 |
| 双击外环扇区 | 选中该分组默认工具，圆盘收起 | 外环扇区 |
| 从中心向外拖动 | 滑到扇区松开即选中 | 中心 + 拖动 |
| 长按空白画布 | 临时弹出圆盘，松手消失 | 画布空白处 |
| 长按对象 | 不弹出圆盘 | 对象 |
| 长按圆盘中心 | 锁定 / 解锁 | 中心圆 |
| 右键圆盘 | 打开配置菜单 | 圆盘任意位置 |
| 拖拽圆盘边缘 | 移动位置 | 圆盘边缘 |
| 双指捏合 | 缩放圆盘大小 | 圆盘任意位置 |

### 5.2 拖拽选中（核心手势）

```text
1. 手指/鼠标按住中心
2. 从中心向外拖动
3. 显示拖拽轨迹线
4. 经过的扇区高亮
5. 松开时选中高亮扇区
6. 圆盘收起
```

细节：

- 拖动距离 < 28px：取消，不选中
- 拖动到内环：高亮内环扇区
- 拖动到外环：高亮外环扇区
- 拖动到外环后继续向外：展开子工具，继续拖动选中子工具
- 松开位置决定选中项
- 支持“回拖取消”：拖回中心松开则取消
- 拖拽时显示轨迹线，从中心到当前指针
- 轨迹线半透明，跟随主题主色
- 轨迹线末端显示当前指向项名称

### 5.3 长按画布弹出

```text
1. 在画布空白处长按 300ms
2. 圆盘以该位置为中心弹出
3. 默认显示内环 + 外环 + 最近使用
4. 松手后如果未选中，圆盘淡出
5. 如果选中，圆盘收起，工具生效
```

不冲突规则：

- 长按空白画布：弹出圆盘
- 长按对象：进入对象上下文，不弹圆盘
- 长按画布已选中对象区域：不弹圆盘
- 长按工具栏/面板：不弹圆盘

### 5.4 键盘操作

| 按键 | 行为 |
|---|---|
| `Space` | 展开 / 收起圆盘 |
| `↑ ↓ ← →` | 在扇区间导航 |
| `Enter` | 选中当前高亮扇区 |
| `Esc` | 收起圆盘 |
| `Tab` | 切换到下一个分组 |
| `Shift + Tab` | 切换到上一个分组 |
| 数字键 `1–6` | 选中内环第 N 个工具 |
| 字母键 | 选中对应快捷键工具 |

键盘导航不播放音效。

## 6. 子工具展开

### 6.1 展开方式

单击外环扇区后，从该扇区向外呈扇形展开子工具。

```text
                    ┌─────┐
                    │ 矩形│
                    └─────┘
              ┌─────┐
              │ 圆  │
              └─────┘
        ┌─────┐
        │菱形 │
        └─────┘
              ┌─────┐
              │箭头 │
              └─────┘
                    ┌─────┐
                    │连线 │
                    └─────┘
```

### 6.2 展开规则

- 子工具从父扇区中心向外辐射
- 子工具半径 120–180px
- 子工具数量 3–6 个时全部显示
- 超过 6 个时，子工具环支持滚动
- 滚动方式：
  - 鼠标滚轮上下滚动
  - 触屏上下滑动
  - 键盘 `↑ / ↓`
- 滚动时父扇区保持高亮
- 其他扇区变暗
- 滚动到边缘有轻微回弹

### 6.3 子工具交互

| 单击父扇区 | 收起子工具 |

| `Esc` | 收起子工具 |

## 7. 状态管理

### 7.1 圆盘状态

```ts
type RadialState =
  | 'collapsed'    // 收起，只显示中心齿轮
  | 'expanded'     // 展开，显示内环 + 外环 + 最近使用
  | 'subExpanded'  // 子工具展开
  | 'dragging'     // 拖拽选中中
  | 'locked'       // 锁定常驻
  | 'hidden'       // 隐藏
```

### 7.2 状态转换

```text
collapsed ──单击中心──▶ expanded
expanded ──单击中心──▶ collapsed
expanded ──单击外环──▶ subExpanded
subExpanded ──选中/点击画布/Esc──▶ collapsed
expanded ──拖拽──▶ dragging
dragging ──松开选中──▶ collapsed
dragging ──拖回中心松开──▶ expanded
任意状态 ──长按中心──▶ locked
locked ──长按中心──▶ collapsed
任意状态 ──右键菜单隐藏──▶ hidden
hidden ──快捷键/菜单──▶ collapsed
```

### 7.3 当前工具显示

- 收起状态：中心显示当前工具图标
- 展开状态：中心显示齿轮，当前工具在内环高亮
- 切换工具后，中心图标 300ms 内过渡到新图标

### 8.2 毛玻璃

- 背景模糊：`backdrop-filter: blur(20px)`
- 边框：1px `#FFFFFF` 20%
- 阴影：`0 8px 32px rgba(0,0,0,0.12)`
- 透明度跟随主题 Token
- 支持“减少透明度”设置

### 8.3 动效

| 动效 | 时长 | 缓动 |
|---|---|---|
| 展开 | 180ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| 收起 | 150ms | `cubic-bezier(0.4, 0, 1, 1)` |
| 子工具展开 | 150ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| 扇区高亮 | 80ms | `ease-out` |
| 中心图标切换 | 200ms | `ease-in-out` |
| 齿轮旋转 | 200ms | `ease-in-out` |
| 轨迹线跟随 | 实时 | 无缓动 |

齿轮旋转：

- 收起 → 展开：旋转 90°
- 展开 → 收起：旋转回 0°

### 8.4 悬停与高亮

- 鼠标悬停扇区：背景变亮，图标放大 1.1x
- 拖拽经过扇区：背景高亮，图标放大 1.15x
- 当前工具：扇区填充主色，图标白色
- 子工具展开时：父扇区保持高亮，其他扇区透明度降至 40%
- 拖拽时：显示从中心到指针的轨迹线
- 轨迹线末端显示当前指向项名称

### 8.5 无障碍

- 所有扇区支持键盘导航
- 焦点环：2px 主色
- 图标有文字标签
- 支持屏幕阅读器
- 支持高对比度模式
- 支持“减少动效”
- 键盘导航不播放音效

## 9. 与其他 UI 的关系

### 9.1 左侧栏

- 左侧栏常驻，圆盘不替代左侧栏
- 左侧栏负责：页面、图层、AI、设置
- 圆盘负责：创作工具
- 两者不重叠

### 9.2 迷你地图

- 迷你地图在圆盘上方，间距 16px
- 圆盘展开时，迷你地图不隐藏
- 若空间不足，圆盘自动向左上展开
- 迷你地图保持可见、可点击

### 9.3 浮动上下文工具栏

- 选中对象后出现，与圆盘不冲突
- 位置：对象上方或下方
- 圆盘展开时，浮动工具栏保持显示
- 圆盘收起时，浮动工具栏正常显示

### 9.4 AI 面板

- AI 面板从左侧栏展开
- 圆盘“更多”里有 AI 入口
- 点击后打开 AI 面板，圆盘收起

### 9.5 透明批注模式

- 透明批注模式下，圆盘隐藏
- 使用右上角专用工具栏
- 退出透明批注后，圆盘恢复

## 10. 边界情况

### 10.1 屏幕边缘

- 圆盘靠近屏幕边缘时，展开方向自动调整
- 右下角：向左上展开
- 左上角：向右下展开
- 支持自动翻转扇区排列

### 10.2 小屏幕

- 屏幕宽度 < 768px 时，圆盘自动缩小
- 总直径从 240px 缩至 180px
- 图标从 24px 缩至 20px
- 标签可隐藏

### 10.3 触屏与鼠标切换

- 检测到触屏输入：圆盘变大，标签显示
- 检测到鼠标输入：圆盘恢复默认
- 手写笔：支持压感，圆盘可半透明
- 不支持触觉反馈

### 10.4 多显示器

- 圆盘跟随主窗口
- 跨屏拖动时，位置正确
- 每个窗口独立圆盘状态

### 10.5 性能

- 圆盘使用独立渲染层，不重绘画布
- 扇区布局计算结果缓存
- 展开/收起动画走 GPU 合成
- 子工具图标预加载
- 最近使用工具图标预加载

## 13. AI 调用

圆盘本身不是 AI 直接操作的对象，但 AI 可以：

```text
“切换到画笔工具”
→ radial.selectTool("brush")

“打开 3D 渲染工具”
→ radial.selectTool("render3d")

“帮我画一个流程图”
→ radial.selectTool("flowchart") + flowchart.create
```

AI 操作时：

- 圆盘对应扇区高亮 300ms
- 中心图标切换到对应工具
- 侧栏显示执行卡片
