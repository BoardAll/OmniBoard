### 4.2 sync 域 op 契约（桌面 ↔ 服务端）

- **key 编码**：`el:{id}:data`（value = 元素契约 JSON，整元素）；删除 `el:{id}:exists=false`（value=false）。
- **op 结构**（crdt 域）：`{actor, seq, key, value, timestamp, origin?}`；`actor` 为每连接会话随机 uuid；`crdt.applyLocal` 补齐 actor/seq/timestamp 并响应完整 op 供直发。
- **出口链路**：画布落定提交（与撤销栈同批）→ `crdt.applyLocal` → `sync.sendOperation` 直发。
- **入口链路**：`sync.events`（drain）→ 生效 op → 画布 upsert/delete（复用元素↔JSON 映射）。
- **防回发**：远端应用期间 `isApplyingRemote` 置位，画布出口跳过（结构防护）。远端 op 不入本端撤销栈。
- **断线差分**：`join` 携带 `lastSeenVersion`（每 actor 最大连续 seq）→ 服务端回放缺口感增量；另配 `board:fetchOps`。

### 4.3 realtime 服务事件集（§6 对齐）【任务记录 + 类型定义复核】

- **M0 POC 兼容层**（非 §6 契约，保留自检）：`board:session` / `board:echo` / `board:broadcast` / `board:direct` / `board:directed`
