# 测试方案设计

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《Flutter + C++ 工程结构设计 v1.0》《Web 端方案设计 v1.0》《构建、打包与发布设计 v1.1》
- 适用范围：Windows / macOS / Linux / Web
- 定位：定义白板软件各层的测试策略、测试环境、测试工具、测试用例、验收标准，不依赖 CI/CD，全部支持本地执行

---

## 1. 设计目标

1. **全层覆盖**：C++ 核心、Flutter UI、FFI、WASM、平台插件、服务端、AI、MCP、Open API。
2. **本地可执行**：不依赖 CI/CD，所有测试可在本地一键运行。
3. **多平台覆盖**：Windows x64 / x86、macOS、Linux、Web。
4. **自动化优先**：能自动化的全部自动化，手工测试只覆盖无法自动化的部分。
5. **性能可量化**：白板、3D、函数、渲染、内存、启动、同步都有明确指标。
6. **安全可验证**：认证、权限、API、MCP、数据、签名都有测试用例。
7. **AI 可测试**：AI 工具调用、MCP 调用、Open API 调用都有测试。
8. **可回归**：每次修改后可快速回归核心功能。
9. **可追溯**：测试用例与需求、缺陷关联。
10. **可交付**：测试报告、缺陷报告、验收报告完整。
