# 可扩展工具栏设计

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.8》《齿轮圆盘交互详细设计 v1.1》《左侧栏与页面管理设计 v1.0》
- 适用范围：Flutter UI + C++ 核心 + 云端 AI + MCP
- 定位：工具栏不是固定按钮，而是可扩展的工具系统，由 ToolRegistry 驱动，上下文动态变化

---

## 1. 设计目标

1. **统一命令层**：所有工具、按钮、AI 调用、Open API 都走同一套命令。
2. **上下文感知**：选中不同对象，工具栏自动切换。
3. **工具联动**：支持“先选颜色，再点表面”这类两步操作。
4. **可扩展**：新工具通过 ToolRegistry 注册，自动出现在工具栏。
5. **不可自定义**：用户不能自定义按钮和圆盘扇区，保证一致性。
6. **AI 可调用**：每个工具栏项都有对应的 Tool，AI 可调用。
7. **跨平台一致**：Flutter UI + C++ 核心，三端行为一致。

## 2. 工具栏架构

### 2.1 分层

```text
┌──────────────────────────────────────────────┐
│ ToolRegistry                                 │
│  工具定义 / 图标 / 快捷键 / 权限 / 确认级别  │
├──────────────────────────────────────────────┤
│ ContextResolver                              │
│  根据选中对象类型，计算应显示的工具栏        │
├──────────────────────────────────────────────┤
│ ToolbarBuilder                               │
│  根据 ToolDefinition 构建 UI 组件            │
├──────────────────────────────────────────────┤
│ Flutter UI                                   │
│  浮动工具栏 / 面板 / 弹出菜单                │
├──────────────────────────────────────────────┤
│ C++ 核心                                     │
│  命令执行 / 事务 / 撤销 / 审计               │
└──────────────────────────────────────────────┘
```

### 2.2 核心概念

| 概念 | 说明 |
|---|---|
| Tool | 一个可执行命令，如 `element.setColor` |
| ToolDefinition | 工具的元数据：名称、图标、参数、权限 |
| ContextToolbar | 一组工具，针对特定对象类型 |
| ToolbarItem | 工具栏上的一个按钮或控件 |
| ContextResolver | 根据选中对象决定显示哪个工具栏 |
| ToolRegistry | 全局工具注册表 |

### 2.3 数据流

```text
用户选中对象
  → ContextResolver 读取对象类型
  → 查询 ToolRegistry 获取对应 ContextToolbar
  → ToolbarBuilder 构建 UI
  → 用户点击按钮
  → 调用 Tool
  → C++ 核心执行命令
  → 画布更新
```

## 3. ToolRegistry

### 3.1 工具定义

```cpp
struct ToolDefinition {
  std::string id;                 // 唯一标识，如 "element.setColor"
  std::string name;               // 显示名称，如 "颜色"
  std::string icon;               // 图标名
  std::string group;              // 分组，如 "style"
  std::vector<std::string> shortcuts;
  std::string scope;              // 权限，如 "element:write"
  ConfirmationLevel confirmation; // Auto / Preview / Confirm
  bool undoable;
  std::string paramsSchema;       // JSON Schema
  std::function<ToolResult(const ToolArgs&)> execute;
};
```

### 3.2 注册方式

- 核心工具：C++ 启动时注册
- 插件工具：插件加载时注册
- AI 工具：与核心工具共用同一注册表
- Open API 工具：从 ToolRegistry 生成

### 3.3 工具分类

| 分类 | 示例 |
|---|---|
| 选择 | selection.set、selection.clear |
| 元素 | element.create、element.update、element.delete |
| 样式 | element.setColor、element.setFont、element.setLineType |
| 布局 | element.align、element.distribute、element.group |
| 层级 | element.bringForward、element.sendBackward |
| 3D | render.3d.pickSurface、render.3d.setFaceColor |
| 函数 | render.function.setStyle、render.function.add |
| 2D | render.2d.setStyle、render.2d.annotate |
| 表格 | table.setCell、table.setFormula |
| 导图 | mindmap.addNode、mindmap.setLayout |
| 流程图 | flowchart.create、flowchart.autoLayout |
| 页面 | page.create、page.duplicate |
| AI | ai.summarize、ai.cluster |

### 3.4 权限与确认

| 确认级别 | 行为 |
|---|---|
| Auto | 直接执行 |
| Preview | 显示幽灵预览，用户确认后执行 |
| Confirm | 弹窗确认 |

| 操作 | 确认级别 |
|---|---|
| 创建元素 | Auto |
| 修改颜色、线型 | Auto |
| 移动、对齐 | Auto |
| 删除单个元素 | Confirm |
| 批量删除 | Confirm |
| 分享白板 | Confirm |
| 修改权限 | Confirm |

### 3.5 撤销与事务

- 每个工具调用生成一个命令
- 多个命令可合并为一个事务
- AI 批量操作合并为一个事务，一次撤销
- 事务记录到历史栈

### 4.2 解析规则

```cpp
ContextToolbar resolveContext(const std::vector<Element>& selection) {
  if (selection.empty()) return defaultToolbar();
  if (selection.size() > 1) return multiSelectToolbar(selection);
  return toolbarForType(selection[0].type);
}
```

class ContextResolver {

### 19.4 工具栏构建

```cpp
struct ToolbarItem {
  std::string toolId;
  std::string icon;
  std::string label;
  bool visible;
  bool enabled;
  bool active;
};

struct ContextToolbar {
  std::string id;
  std::string target; // none / selection / element / canvas
  std::vector<ToolbarItem> items;
};

class ToolbarBuilder {
public:
  ContextToolbar build(const std::vector<Element>& selection);
  std::string toJson(const ContextToolbar& toolbar);
};
```

## 20. AI 调用

### 20.1 AI 调用工具

```text
“把选中的便签改成蓝色”
→ element.setColor

“把 3D 长方体的顶面涂成蓝色”
→ render.3d.pickSurface + render.3d.setFaceColor

“把函数曲线改成虚线红色”
→ render.function.setStyle

“自动整理这个流程图”
→ flowchart.autoLayout

“给这个表格添加求和公式”
→ table.setFormula
```

### 20.2 AI 操作反馈

- 工具栏对应项高亮 300ms
- 画布显示幽灵预览
- 侧栏显示执行卡片
- 完成后可撤销

### 20.3 AI 与工具栏一致

- AI 调用与用户点击走同一命令
- 权限一致
- 确认级别一致
- 撤销一致
- 审计一致
