# 主题与背景系统设计

- 文档版本：v1.0
- 状态：详细设计稿
- 所属文档：《白板软件设计文档 v0.8》《齿轮圆盘交互详细设计 v1.1》《渲染引擎设计 v1.0》
- 适用范围：Flutter UI + C++ 核心
- 定位：主题系统负责全局视觉风格，背景系统负责画布背景；两者独立但可联动

---

## 1. 设计目标

1. **主题可替换**：颜色、图标、UI 图片、字体、圆角、阴影、密度全部可替换。
2. **背景多类型**：白板、黑板、绿板、点阵、网格、纹理、图片、渐变。
3. **按页面设置**：每个页面可独立设置背景。
4. **运行时切换**：主题和背景切换不重启、不丢状态。
5. **主题包**：支持导入/导出主题包，支持内置主题。
6. **透明度跟随主题**：圆盘、工具栏、面板透明度由主题 Token 控制。
7. **黑板联动**：黑板/绿板模式联动默认画笔、文字、便签颜色。
8. **性能**：背景纹理缓存，主题切换只替换引用，不重绘全部元素。
9. **可访问性**：高对比度、减少动效、暗色模式。
10. **AI 可调用**：主题和背景操作有对应 Tool。

## 3. 主题系统

### 3.1 主题层级

```text
主题包 Theme Pack
  ├── meta          名称、作者、版本、预览图
  ├── colors        颜色 Token
  ├── typography    字体、字号、行高
  ├── shape         圆角、边框、阴影
  ├── icons         图标包
  ├── images        UI 图片资源
  ├── sounds        音效（可选）
  ├── canvas        画布背景默认值
  └── overrides     组件级覆盖
```

### 3.2 主题模型


### 6.4 黑板模式

黑板模式不只是换背景色，还联动：

- 默认画笔颜色变白
- 默认文字颜色变白
- 便签颜色适配
- 网格点变浅
- 工具栏主题可联动
- 字体可选粉笔感

绿板模式类似，默认白字，背景墨绿。

### 6.5 按页面设置

- 每个页面可单独设置背景
- 支持应用到全部页面
- 支持从模板继承
- 支持复制页面时保留背景

### 6.6 背景渲染

```cpp
class BackgroundRenderer {
public:
  void render(RenderContext& ctx, const Background& bg, const Rect& viewport);
  void invalidate(const std::string& backgroundId);

private:
  std::unordered_map<std::string, std::string> textureCache_;
  std::mutex mutex_;
};
```

渲染策略：

- 纯色：直接填充
- 点阵 / 网格：程序生成纹理，缓存
- 纹理：加载图片，缓存
- 渐变：GPU 渲染
- 图片：纹理平铺或拉伸
- 只重绘背景层，不重绘全部元素

### 6.7 背景性能

| 类型 | 性能 |
|---|---|
| 纯色 | 极快 |
| 点阵 / 网格 | 快，纹理缓存 |
| 纹理 | 中，纹理缓存 |
| 渐变 | 快，GPU |
| 图片 | 中，纹理缓存 |

优化：

- 纹理缓存
- 按页面缓存
- 缩放时不重绘背景（使用纹理缩放）
- 视口变化时只更新偏移

## 8. 交互设计

### 8.1 主题切换

```text
1. 打开设置 > 主题
2. 浏览主题列表
3. 点击预览
4. 实时预览
5. 确认应用
6. 主题切换，颜色过渡 200ms
7. 图标切换 150ms 淡入
8. 图片切换 200ms 淡入
```

### 8.2 背景切换

```text
1. 打开设置 > 背景
2. 选择背景类型
3. 调整颜色、网格、透明度
4. 应用到当前页 / 全部页
5. 即时生效
```

### 8.3 主题包导入

```text
1. 打开设置 > 主题
2. 点击“导入主题包”
3. 选择 .zip 文件
4. 校验格式
5. 预览
6. 确认导入
7. 主题出现在列表
```

### 8.4 主题包导出

```text
1. 打开设置 > 主题

3. 点击“导出”
```
